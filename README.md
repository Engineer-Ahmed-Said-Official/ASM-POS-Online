## 🌟 نبذة عن البرنامج

برنامج **ASM Online** هو جزء أساسي من منظومة **ASM POS** لإدارة نقاط البيع والمتاجر. صُمم خصيصاً لتسهيل استقبال ومتابعة وتسليم طلبات الدليفري والأونلاين بسرعة فائقة، مع دعم العمل في وضع عدم الاتصال (Offline) والمزامنة الفورية مع السيرفر السحابي.

---

## 🚀 المميزات الرئيسية

* ⚡ **مزامنة فورية ودقيقة**: سحب المنتجات والمخزون والعملاء تلقائياً مع السيرفر السحابي.
* ⚖️ **دعم متكامل لمنتجات الوزن والميزان**: إمكانية البيع بالكسور العشرية (ربع كيلو، نصف كيلو، إلخ) مع أزرار مساعدة سريعة.
* 📦 **تعدد أسعار البيع**: دعم بيع الكرتونة، والقطاعي، والجملة، ونصف الجملة.
* 🔌 **العمل في وضع الأوفلاين (Offline)**: تسجيل الفواتير والطلبات بدون انقطاع ومزامنتها تلقائياً عند عودة الإنترنت.
* 🔄 **تحديث تلقائي آمن (Self-Update)**: فحص وتثبيت التحديثات بضغطة زر مع التحقق المشدد من سلامة الملفات عبر بصمة SHA-256.
* 🖨️ **طباعة فواتير وإيصالات سريعة**: دعم طابعات الكاشير الحرارية (Thermal Receipt Printers) بجميع مقاساتها.
